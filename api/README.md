# API (NestJS)

Бэкенд для HR-приложения (управление организациями, отделами, должностями).

## Установка

Выполните команду:
**npm install**

## Настройка переменных окружения

Создайте файл `.env` в папке `api` (или скопируйте `.env.example` из корня проекта) и укажите строку подключения к базе данных:
**DATABASE_URL=postgres://postgres:secret@localhost:5432/hr_db**

## Запуск

Для запуска в режиме разработки выполните:
**npm run start:dev**

## Миграции

Чтобы применить миграции, выполните:
**npx node-pg-migrate up --envPath .env**

Чтобы откатить последнюю миграцию, выполните:
**npx node-pg-migrate down --envPath .env**
